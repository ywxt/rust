
# contains 联合验收：未达标

**结果：未达标，没有保留新的标准库优化。** 本轮所有候选均存在可重现的性能回退，不能以长输入的收益替代完整接口的验收。不设“回退几个百分点也算通过”的豁免。远端实际仓库的 memchr.rs 已恢复冻结的 main 实现，cmp.rs、pattern.rs 也处于本轮 main 基线；隔离构建目录保留失败实验。未修改本地仓库，未提交或推送。

### 明确失败的反例

| 已淘汰版本与场景 | ARM main cycles/op | 实验 cycles/op | 变化 |
|---|---:|---:|---:|
| portable SIMD，16 B 对齐 byte slice 未命中 | 11.329 | 12.329 | +8.83% |
| 完整索引 SIMD，128 B、第 64 B 命中 | 28.976 | 40.072 | +38.29% |
| 短尾部调整，33 B char 未命中，九轮 | 16.352 | 16.597 | +1.50% |
| word4，16 B 偏移 1、最后命中 | 33.329 | 34.317 | +2.96% |
| word4 退出调整，128 B 首字节命中 | 17.329 | 18.335 | +5.81% |

所有数字来自真实重编译标准库的固定次数驱动，非替代 contains 功能的专用感叹号探针。普通表项各三轮交替成对测量；标注九轮的表项增加了迭代次数。完整中位数、范围、样本数与未完成项在结果文件中保留。部分版本只跑到发现失败反例即停止，不声称每一版都完成相同覆盖。

### 收益与跨架构比较的边界

长文本、单字节未命中仍有明显收益，但只是已经淘汰方案中的局部结果：

- contains-arm-mask-abi-20261106: 607.738 → 158.390 cycles/op（-73.94%）
- contains-arm-word4-20261106: 673.760 → 554.608 cycles/op（-17.68%）

x86 分支沿用 main。已验证 x86 参考组被测程序的完整 ELF 相同，标准库 .text 相同；这些候选没有可归因于源码的 x86 加速。x86 全量参考批次的部分长样本范围较宽，同码进程也出现明显中位数差异，不能将其当作源码收益或据此给出精确硬件优势。跨架构 CSV 同时保存固定 x86-main 分母和实测两组分母的比值，保留原始范围，避免掩盖这一限制。第一项“不回退”已经失败，因此不宣称两项联合达成。

### 源码与机器码归因

- 布林存在性不需要首个命中索引；恢复索引的 SIMD 路径在首个向量块较早命中时可能增加延迟。完整索引对照检查通过并不代表性能没有代价。
- 短输入的向量归约、word 扫描及尾部重读有不同成本。16 B 未命中、只剩 1 B 尾部、31 B 等场景分别出现过回退；单一阈值和重叠尾部不能覆盖所有情况。
- 私有助手返回 bool 会改变调用端结果归一化及代码布局；返回 0/1 整数并与 1 比较可以保持原有判定形状，但未消除所有回退。实际 IR、汇编与源码均归档。
- word4 的 128 B 完整未命中曾恰好多一条指令和一个分支，实际汇编对应退出时的无条件跳转。修正该出口后又出现新的首字节命中回退，仍不能保留。函数位置、标量前缀及共享尾部的布局也会随实现变化；未把这些观察直接当作已证明的某项硬件缺陷。

### 方法与范围

ARM 使用用户指定的 920B，记录 MIDR 为 0x00000000480fd020，固定 CPU 52；x86 使用当前 i7-12700 的 CPU 12。使用同一 ARM-host Rust 1.99.0-dev / LLVM 23.1.0 编译器构建两个 GNU target。应用编译参数保持一致，包括原有 -Zinline-mir；没有新增 inline 属性，也没有用修改 x86 路径来扩大 ARM 优势。关闭 ASLR、交替版本顺序，perf stat 记录 cycles、instructions、branches、branch-misses、task-clock、上下文切换和迁移。进程计数除以固定迭代次数，包含初始化成本，不等同于完全隔离初始化的接口延迟。

main 指冻结的 contains/memchr 实现对照，来源 main ref 811367e98c08549865a32553076d617fb63154ef；构建源 HEAD 为 dc55da5cca14a0aa773ecb7a0459756260b2ee5c。无关的既有改动在成对构建中保持固定，不是整个仓库 clean-main 的重新构建。

最后两版每个 ARM 构建通过 26,035,680 项独立功能对照，覆盖 contains、byte slice、首个命中索引及匹配顺序，另有自定义 Pattern 与谓词副作用检查。全部 256 种 byte needle、不同偏移、空输入、Unicode、多 byte needle 和多种 Pattern 均有正确性覆盖。完整 coretests/alloctests 在若干中间版本通过；最后两版未作为可交付实现继续跑全套官方测试，因为性能反例已经使其不合格。有限覆盖不能证明任意输入与构建配置都不回退。

证据位于 [contains-no-regression-20261106](README.md)。[全部成对结果](all-paired-results.csv)、[逐版覆盖](coverage.json)、[已淘汰 SIMD 的双平台参考](rejected-mask-cross-arch.csv)、每版 candidate.patch、原始 JSON 与正确性日志均已保存。只用于个人实验，不作为可提交优化方案。

目录说明：rejected 下每个目录对应一次独立候选；effective-source 与 candidate.patch 是该版有效源码。JSON 中保存各次 perf 计数，CSV 提供汇总；coverage.json 明确不完整批次。x86-reference 是整数掩码候选的全量同码参考，不能与其他版本混作同一组配对实验。common 中保存冻结的 main 源码与编译器版本。复现固定次数驱动使用各目录保存的 build-harness.py、原始命令与 sysroot-manifests.json，原始冻结构建仍位于对应 /tmp/contains-* 目录；不应修改被测 ELF 做审计。
